# Dashboard de suivi de la production automobile

Projet YaneCode Academy, MEGGOURI Amine.

## Structure

```
dashboard_production/
├── app.py                 Application Streamlit (connexion + dashboard)
├── dataset.csv            Données de production horaire (30 000 lignes)
├── requirements.txt       Dépendances Python
├── README.md              Ce fichier
└── .streamlit/
    └── config.toml        Thème (couleurs) de l'application
```

## Lancer le projet

```bash
pip install -r requirements.txt
streamlit run app.py
```

Connexion : utilisateur `Amine`, mot de passe `0000`.
